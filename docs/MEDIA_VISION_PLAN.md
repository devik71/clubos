# BRUKXT Media Engine vision

Local React / Next.js / TypeScript presentation. Existing ClubOS documentation and HTML vision remain separate. No backend or real OBS, file or messaging operations.

## Story architecture (SPIN)

1. Situation: the set ends, but the team's work does not.
2. Problem and implication: an accumulation of small manual tasks becomes a queue, lost context and late failures. Collapse that workflow into three steps.
3. Need/payoff: simulate pre-flight, automatic direction, failure recovery and immediate human control; follow the set through post-production and delivery.
4. Evidence and feasibility: immutable audio, a shared timeline, BRUKXT Editing Grammar, a cooperating technical crew, cautious archive reconstruction, a two-camera test bench and five incremental layers.
5. Close: one ClubOS module shares events and context; human attention moves to physical, creative and exceptional work.

## Visual system

Helvetica Neue / Helvetica / Arial. Black, white and neutral grays only. Editorial display type, generous whitespace, thin dividers, restrained control-room panels. No logos, photos, external fonts, paid services or SaaS conventions. Ukrainian narrative and concise technical labels. Desktop presentation first, responsive down to 360px.

## Reusable components

Chapter / section heading, segmented control, status, inspectable node, camera view, waveform, playback control, detail disclosure. Explicit demo labels. Button press feedback, reversible transitions, visible keyboard focus, native range input and reduced-motion support. Apply Emil Kowalski's apple-design skill, read from its upstream SKILL.md on 2026-09-20.

## Validation

Production build and TypeScript. Deterministic simulation tests: failed and excluded sources never go to program, manual lock persists, recovery respects exclusions, human notification follows exhausted recovery. Browser checks for keyboard, collapse, pre-flight, automatic and manual direction, both failure outcomes, pipeline playback, publication hold, archive review and narrow layouts.
